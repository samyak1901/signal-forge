# 0002: Vite React Frontend

## Status

Accepted

## Context

SignalForge needs a polished research dashboard, but the early product is an application shell rather than a content-heavy public website.

## Decision

Use Vite React with TypeScript for the frontend.

## Consequences

- Faster development loop.
- Simpler deployment model for the dashboard.
- Clear separation between API and frontend.
- Routing and data fetching remain explicit application concerns.
